# Code of Conduct

## Our Pledge

We want Findora to be a welcoming, respectful, and beginner-friendly open-source project.

Everyone participating in this project is expected to show respect, patience, and professionalism.

## Expected Behavior

Examples of positive behavior include:

- Being respectful and helpful
- Giving constructive feedback
- Welcoming beginners
- Explaining decisions clearly
- Focusing on the project goal

## Unacceptable Behavior

Examples of unacceptable behavior include:

- Harassment or personal attacks
- Insulting or disrespectful comments
- Discrimination of any kind
- Sharing private information without permission
- Spam or intentionally harmful contributions

## Enforcement

Project maintainers may remove comments, close issues, reject pull requests, or block contributors who violate this code of conduct.

## Scope

This code of conduct applies to all project spaces, including:

- GitHub issues
- Pull requests
- Discussions
- Documentation
- Community communication related to Findora
